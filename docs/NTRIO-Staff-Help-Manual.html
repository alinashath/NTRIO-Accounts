1. Getting started

  1. Open the NTRIO app in your browser and sign in.
  2. You land on Workspaces. Choose one:
    • Occupancy — rooms and guest stays (calendar)
    • Kitchen — breakfast orders, server list, KOT
    • Stock — inventory, shopping list, cost reports
    • Accounts — money (not covered in this guide)
  3. Tap the NTRIO header anytime to return to Workspaces.
  4. On phone, use the bottom tabs. On desktop, use the top links. More opens other workspaces and Sign out.
Golden rule Put stays in Occupancy first. Then take breakfast orders in Kitchen for that date. Stock and KOT use those orders automatically.

3. Occupancy — rooms & stays

Front desk Path: Workspaces → Occupancy

3.1 Rooms

  1. Open the Rooms tab.
  2. Tap Add room, enter the room number (e.g. 101), save.
  3. Delete only if the room has no breakfast history (system will block otherwise).

Rooms appear on the stay calendar and on Kitchen breakfast boards.

3.2 Stay calendar (Stay view)

  1. Open Stays (home of Occupancy).
  2. Use the arrows to change month.
  3. Grid = rooms down, dates across.
  4. Filled (dark) cell = occupied. Number = guest count.
  5. Empty cell = vacant. Tap to start Add stay for that room/date.
  6. Or tap Add stay at the top and fill the form.
Add stay fields
  • Room — which room
  • From / To — inclusive dates (every night in range is filled)
  • Occupants — how many guests in the room
  • Notes — optional (e.g. guest name, booking ref)

3.3 Remove a stay

  1. Tap a filled cell, or a row under Stays this month.
  2. Confirm Remove stay.

Removing a stay clears occupancy for those dates (unless another stay still covers them).

4. Kitchen — breakfast orders

F&B / night staff Path: Workspaces → Kitchen → Orders

4.1 Pick the date

Set the Date at the top to the breakfast morning you are preparing for.

4.2 Per room

Each room card shows occupants (from Occupancy) and how many breakfast guests are already ordered.

Icon / actionUse it for
People (occupants)One-day occupant override only. Prefer Occupancy for from–to stays.
Fruit / extrasFruits (2–3 types or none), pancake, honey, Nutella, cereal, water bottle
Add breakfast (+)New guest breakfast order for that room
Tap an existing orderEdit, mark served/cancelled, or remove

4.3 Breakfast order fields

  • Guest number — 1, 2, or 3 in that room (one order per guest)
  • Breakfast type
    • Maldivian — 5 Roshi · 1 Mashuni · Egg (default omelette) · optional stir-fried potato
    • Continental — 3 bread · 2 sausages · 2 butter · 1 jam · Egg (default fried)
  • Egg style — omelette, fried, boiled, or scrambled
  • Beverages — juice, tea, coffee, milk, sugar (tick what is needed)
  • Serving time — normal window times, or tick Special time outside 7:00–9:30 for early/late (departing guests). Outside times are flagged for the kitchen.
  • Special requests — free text
  • Status — Pending → Served (or Cancelled)
Important Occupied rooms do not automatically get breakfast. Only guests with a saved order appear on the server summary and KOT.

5. Kitchen — server summary & KOT

Servers & kitchen Path: Kitchen → KOT

Choose the same Date as Orders.

5.1 Breakfast summary for servers

List of rooms with Maldivian / Continental counts, juice, tea/coffee, special requests, and outside-window flags.

Share actions (icon row):

  • Copy — paste into WhatsApp / Viber as text
  • CSV — spreadsheet download
  • PNG — large readable image for chat apps
  • Print — print or Save as PDF from the browser

5.2 KOT / Kitchen plan

Totals the kitchen needs to prep (Roshi, Mashuni, sausages, eggs by style, potato, pancakes, etc.).

  • Only items with quantity greater than zero are shown and exported.
  • Preparation schedule lists each guest by time, room, type, and egg style.
  • Same share icons: Copy · CSV · PNG · Print — use PNG for WhatsApp / Viber.

6. Kitchen — recipes

Supervisor Path: Kitchen → Recipes

Recipes link stock items to breakfast rules (what gets consumed when an order is placed). Change only if you know the Isola Alifu portion rules. Stock items must exist under Stock → Inventory first.

7. Stock — inventory, shopping, reports

Store Path: Workspaces → Stock

7.1 How inventory is deducted (Used)

  1. When you save a breakfast order or room extras, NTRIO calculates ingredients from Isola Alifu Use rules.
  2. Those quantities are written to the stock ledger as Used for that breakfast date (automatic).
  3. Balance = Opening + Received − Used. A “Low” tag appears when Balance is under Min stock.
  4. Stock → Inventory → Re-sync breakfast usage re-runs the same calculation if you need to refresh.
  5. Enter Received when deliveries arrive. Set Min stock on each item (tap the row) so shopping tops up to that level.

7.2 Shopping list (after orders)

  1. Place / edit breakfast orders for the date (Kitchen → Orders). The app updates usage and shopping.
  2. Open Stock → Shopping for the same date (or tap the link shown after saving an order).
  3. To buy includes:
    • Order shortfall — not enough on hand for that morning’s orders
    • Below min — after covering orders, stock would fall under Min stock (or is already under min)
    • Not in stock — required ingredient missing from the inventory catalog
  4. Formula: buy enough so on hand + buy − order need ≥ Min stock.
  5. Copy / Download / Print the list for purchasing. On-hand for shopping is Opening + Received (before Used), so the list does not double-count.

7.3 Inventory screen

  1. Pick the date.
  2. Tap a row to edit Opening, Received, Used, Waste, Expenditure, and Min stock.
  3. Add stock item for new kitchen or other items (e.g. toilet tissue).
  4. Download inventory for a CSV backup.

7.4 Cost & waste reports

Choose a date range to see consumption, spend, cost context, and waste. Download CSV if needed for Accounts.

9. Tips & troubleshooting

  • Room missing on Kitchen? Add it under Occupancy → Rooms.
  • Calendar empty? Add a stay (from–to). Occupancy does not invent guests.
  • KOT empty? No breakfast orders for that date, or all cancelled. Orders drive KOT.
  • Shopping empty but you expected buys? Check the same date as orders; set Min stock > 0; enter Opening/Received so on-hand is correct.
  • Balance looks wrong after cancelling orders? Saving/removing orders re-syncs Used. Or tap Re-sync breakfast usage on Inventory.
  • Outside window flag? Guest chose a time outside 7:00–9:30 — prep early/late.
  • PNG not opening in chat? Download PNG (not CSV). Text Copy also works in WhatsApp/Viber.
  • Wrong month on calendar? Use the left/right arrows in Stay view.
  • Cannot delete room? Remove breakfast order history for that room first, or ask a supervisor.
  • Sign out — More → Sign out (or desktop top bar).
Need help? Ask your supervisor. Do not share login passwords. Keep guest notes professional (names/refs only).
